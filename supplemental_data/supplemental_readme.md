# Supplemental Data

This directory contains all supplementary figures, tables, and datasets associated with the preprint of the manuscript:

**Population-scale transcriptomics reveals host genetic control of phyllosphere fungal communities**

---

## Contents

### Supplementary Figures

All supplementary figures (S1–S7) are compiled into a single PDF:

- `Supplementary_figures.pdf`

Includes:
- Fungal read count distributions across datasets
- Cross-dataset fungal taxon overlap across taxonomic levels
- GO and KEGG enrichment results for TWAS-associated genes
- Genome-wide distributions of GWAS and eQTL peaks

---

### Supplementary Tables

All supplementary tables (S1–S10) are provided in a single Excel workbook:

- `Supplementary_tables_combined.xlsx`

Includes:
- Taxon filtering summaries across datasets
- GWAS significance thresholds and marker summaries
- Heritability estimates
- TWAS, GWAS, and eQTL association results
- Genomic hotspot region summaries
- Gene–trait and gene–taxon association tables

---

### Supplementary Datasets

- **S1. Maize fungal abundance matrix**  
  Filtered samples passing the 2,500 fungal-read threshold prior to winsorization and genotype-level selection.

- **S2. Sorghum fungal abundance matrix**  
  Filtered samples passing the 2,500 fungal-read threshold prior to winsorization and genotype-level selection.

- **S3. Soybean fungal abundance matrix**  
  Filtered samples passing the 2,500 fungal-read threshold prior to winsorization.

- **S4. Orthogroup assignments for TWAS-significant genes**  
  Cross-species orthology mapping for TWAS-associated genes.

---

## Notes

- Figures are provided as publication-ready PDF.
- Tables are provided as a single Excel workbook for convenience.
- Datasets are provided in CSV format.
- All analyses and generation scripts are available in the main repository.
